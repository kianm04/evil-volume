# scream volume

A 3D volume control that screams at its own volume. Pump it up and it gets louder, higher and more upset.

## what it is

An evil volume input: you pump the volume up by hand, it leaks back down, and a 3D head screams at whatever volume it is currently set to. Other heads turn up and join in, out of tune.

## what input it collects

A volume from 0 to 100%. You pump it up by hand while it leaks (faster the louder it gets). The OK button asks you to confirm a number that is still leaking, so you never save the one you wanted. The mute button only makes it hold the scream in until it bursts back out. Sometimes it switches to opera, or becomes a goat. Go over 100% and it explodes.
